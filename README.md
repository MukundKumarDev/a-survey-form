# Responsive Survey Form

A clean, modern, and accessible survey form built with HTML5 and CSS3 as part of the freeCodeCamp Responsive Web Design certification.

## 🛠️ Features

- **Responsive Design:** Mobile-first approach using CSS Flexbox and Grid for seamless viewing across devices.
- **Custom Theme:** Built with CSS variables (`:root`) for easy color management and a modern light interface.
- **Micro-interactions:** Interactive form inputs with custom focus animations and hover states.
- **Form Validation:** Built-in HTML5 validation for text, email, and number inputs.

## 🧰 Tech Stack

- **HTML5:** Semantic markup structure
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Media Queries

## 🚀 What I Learned

- How to structure clean, accessible form controls.
- Managing 2-column layouts on desktop using CSS Grid.
- Aligning radio buttons and checkboxes effectively using Flexbox.
- Creating reusable color schemes with CSS Custom Properties.
